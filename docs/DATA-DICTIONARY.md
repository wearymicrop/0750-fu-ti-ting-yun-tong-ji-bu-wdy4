# 数据字典

## 输入

| 字段 | 含义 |
|---|---|
| `start`、`end`、`cutoff` | 统计起点、终点、采信时刻。带偏移的 ISO 8601 整秒，支持 `Z`。窗口最多七天，采信时刻位于窗口内 |
| `devices[]` | `device` 为字符串设备号，保留前导零，`name` 为设备名称 |
| `shifts[]` | `device`、东八区起始日期 `day`、本地整秒时钟 `from` 与 `to`。结束时钟早于开始表示次日，两个时钟相同视为无效 |
| `events[]` | `device`、设备内报码 `id`、`start`、`end`、`reason`。`end` 为 `null` 或缺失代表未恢复，空字符串无效 |
| `permits[]` | `device`、审批编号 `id`、`start`、`end`、`reason`、`status`、`approval`。`reason` 为 `null` 时适用于该设备全部确认停运原因 |

`devices`、`shifts`、`events`、`permits` 上限分别为 50、500、1000、500 行。证据行号从各输入数组的第一行计为 1。坏行保留原值和隔离原因。日期范围为 2000 至 2099 年，东八区班表使用固定 UTC+08:00。

## 时间与分段

所有区间采用 `[start, end)`，服务端以 Unix 整数秒计算、汇总并输出。班次相交或相邻先取并集。事件与营业窗口、采信窗口求交，裁掉非营业秒和采信范围之外的时间。采信时刻之后直到营业终点的片段记为缺证。

| 优先级 | 原因码 | 原因 |
|---:|---|---|
| 10 | `SAFETY` | 安全联锁 |
| 20 | `POWER` | 供电中断 |
| 30 | `MECHANICAL` | 机械故障 |
| 40 | `MAINTENANCE` | 计划检修 |

同级先比较原始起点，再比较报码和来源行。确认事件优先于缺证候选。未恢复、未知原因、同设备同报码冲突的可定位片段归入缺证。设备不在册或时段无效的事件留在隔离记录，无法据此分配时长。

同设备同报码且起止秒与原因相同，保留首行并记录后续重传。有效载荷冲突时，各版本均保留为隔离记录，能落在营业窗口的争议区间进入缺证候选。每段记录所有相交报码行与唯一归属行。审批必须为 `approved` 且提供 `approval`，仅匹配设备和获胜原因的时段可获豁免。多个审批交叠只计算一次，所有适用审批行继续留在片段上。

## 对账与归档

`service = available + responsible + exempt + missing`。每台设备单独核对差额。可用率分母为 `service - exempt`，按百分之一百分点四舍五入输出整数基点。缺证时确认可用率为空，可用率下限按已确认可用秒计算。分母为零时两者均为空。

班报 ID 由输入摘要、来源及规则版本生成。输入与结果独立保存 SHA-256 摘要，结果摘要不包含耗时。对象属性排序后序列化，数组顺序保留以保护证据行号。重跑使用 SQLite 中保留的原始输入，重算摘要与班报 ID 后核对。证据附件包括输入、运行清单和所有片段。按片段起点查询可取回对应报码、重传、班表、审批和计算分类。
